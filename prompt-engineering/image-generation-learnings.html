Image generation learnings

A report on prompting AI image models, built from three colouring book projects.

Back to learnings

Overview

This report collects what worked and what failed while generating illustrations for a series of adult colouring books. Every learning is a cause and effect seen across several generations. None of them is a guess.

3
Volumes: Norse Vættir, Yokai and Oni of Japan, Ajaib of Egypt, Babylon and Persia
50
Creature illustrations planned for each volume
4
Source learning documents merged into this report

The setting

All three volumes used Grok Imagine (grok-imagine-image). The target was strict black line art on pure white, with no fills of any kind, so a colourist could work on the page. This is a hard constraint. Image models drift towards shading, grey and solid black, so the prompts had to push back on every default.

The Norse volume used a fine anatomical engraving style. The Ajaib volume adapted the same template. The Yokai volume used a bolder horror line art style. The lessons overlap heavily, which is why they hold up beyond any single book.

The ten principles

  • Describe the form, not the name. The model's knowledge of niche mythology is shallow.
  • Build from human anatomy. Category words such as demon or giant trigger cartoon templates.
  • Describe what is present. Negations often make the model draw the unwanted thing.
  • List every hollow. A generic ban on solid black protects only the obvious cases.
  • Imply time through objects. Never state the time of day.
  • Repeat scale and key anatomy. A single mention is treated as optional.
  • Use culture-specific vocabulary. Generic nouns produce generic or wrong results.
  • Give camera and intent, not coordinates. Over-constrained layouts break anatomy.
  • Avoid moderation triggers. Some phrases cause rejections that content alone does not.
  • Review before you generate. Every generation costs a credit.

Style template

Each volume locks one opening paragraph and one closing paragraph. Every prompt shares them. This keeps linework consistent across fifty pages and leaves the middle of the prompt free for the subject.

Locked opening

The opening names the art form, the historical sub-style and the fill rules in one block.

Adult coloring book page illustration of a Norse mythology [creature], in the style of fine anatomical engraving line art, like a 19th century [zoological / medical / natural history / geological / ornithological / maritime] illustration. Pure monochrome design with clean, naturalistically varying linework, crisp black contour lines, and completely empty white spaces. Formatted for an adult coloring book template with zero solid black fill-ins, no shading, no gradients, no grayscale, and no cross-hatching.

Locked closing

The closing sets orientation, full bleed and the ban on text.

Portrait orientation, taller than wide. Full bleed composition, artwork extends to every edge of the page with no border, no frame, no margin. Background elements, foreground elements, and all linework must run completely off every edge of the canvas, with no visible page boundary, no safe zone, and no white gutter around the perimeter. Treat the image frame as a window cropping into a larger continuous scene rather than a contained composition. No text, no lettering, no signature.

Only one page per volume used landscape orientation. It swaps the first sentence for "Landscape orientation, wider than tall."

The Yokai volume used a different header

The Yokai prompts used bold uniform linework and a fixed adult horror register sentence in the header. The header was not enough on its own. The creature description also needed tone words, which section 3 explains.

Pure monochrome design featuring clean bold linework, crisp black outlines, completely empty white spaces, and all shapes fully closed. Rendered in adult horror register. Consistent uniform line weight throughout all elements.

The same header also carried a realism line for backgrounds, covered in section 5.

Describing subjects

Most failed generations traced back to how the subject was described. The model fills any gap with its most common training image. These learnings close those gaps.

3.1 Describe the visual form, not the name

Rule. Do not let a proper name carry the visual. Lead with the physical form. Treat the name as optional flavour at the end.

Why. The model maps names to shallow training associations. Draugr produced a plain skeleton. Huldra produced an ordinary woman. Álfar produced a modern human. Kuchisake-onna produced a modern woman and Pazuzu risked a generic winged demon.

Apply. Write the body, the key features and their placement before any mythological name.

3.2 Build humanoids from human anatomy up

Rule. Never open with a category word such as giant, ogre, demon, monster, zombie, undead or beast.

Why. Category words anchor the model to a cartoon template. That means exaggerated faces, comic proportions and flat frontal staging.

Apply. Start with a human base, describe its anatomy, then add each supernatural feature with an exact placement.

WeakAn ogre with horns.
StrongerA large powerful human male, broad-shouldered and heavily built. Two curved horns emerge from the forehead above the brow line.

3.3 Set the tone inside the description

Rule. For a horror register, put tone words in the creature description and not only in the style header. Use words such as ancient, malevolent, predatory, unsettling, menacing, grim and cold menace.

Why. Words like jolly, mischievous, playful, wide grin and dancing push the model to a children's book style whatever the header says.

Apply. For trickster creatures that are not full horror, replace mischievous with "sly, grim". Add "realistic" before each key anatomy element, such as "realistic beak-like mouth". The Kappa entry confirmed this approach.

Book-wide, the header should also state the register once, for example "Rendered in adult horror register", so the tone holds even for beautiful or tragic creatures.

3.4 A tight grimace beats an open roar

Rule. For powerful humanoids, use a controlled grimace.

Why. The roaring mouth is the standard fantasy attack pose. It locks the model into a cartoon monster. A grimace reads as cold menace and keeps the model in human anatomy mode.

Mouth: lips set in a tight controlled grimace, pulled back slightly at the corners, teeth just visible at the edges. Not open, not roaring. An expression of cold fury.

Exception. When the open jaw is the horror, as with the crocodile-headed Ammit, describe the jaw in detail. Show the teeth in a natural row and keep the interior as an empty white space.

3.5 Horror comes from position, not scale

Rule. Keep abnormal features at realistic size. Describe exactly where they sit.

Why. A giant eye or an enormous wound reads as cartoon. A normal-sized feature in the wrong place lets the viewer almost accept it before the wrongness registers. That delay is the unease.

  • State size against normal anatomy, such as an eye of normal human size, no wider than a quarter of the face.
  • Use anatomical coordinates, such as at the horizontal midline where the nose bridge would sit.
  • Name each absent feature and where it would normally be.
  • Never write vast, enormous or filling the face. Never write wrong placement. The model cannot draw an abstraction, so describe the place itself.

The Hel prompt split the body along the vertical midline. One side was living flesh. The other showed decomposition, with the shape of the clavicle and ribs readable through taut skin. Hitotsume-kozo and Noppera-bo used the same method.

3.6 Name the attachment point of impossible features

Rule. For grafted or grown features, say where the feature emerges and how the surrounding tissue responds.

Why. Without an attachment point, the model floats the feature beside the body. The tissue response sells it as real.

From each trapezius muscle, where the shoulder meets the neck, a serpent emerges. The flesh of the shoulder is split and closed around the serpent's base as if it grew there from birth. Skin contours are tight and radiate outward from the emergence point.

Describe the serpent at a scale matched to the shoulder width. Do not make it giant.

3.7 Composite bodies need a part-by-part list

Rule. List every body part with its source animal. Never write composite or hybrid as shorthand.

Why. A bare composite demon produces a generic winged humanoid. The model invents its own mix.

3.8 Describe only what is unnatural

Rule. Trust the model on familiar anatomy. Spend words only on features that are impossible or specific to the creature.

Why. Over-describing scale patterns, toe pads or feather counts crowds out the unusual features. The prompt starts to read as an anatomy lesson, not a portrait.

Test. Ask whether a competent natural history illustrator would draw the detail correctly from the species name alone. If yes, leave it out. Write "a great venomous snake" and "broad eagle wings". Describe in full only the horns on the snake or the legs that sprout from its body.

3.9 State critical anatomy twice

Rule. Say the defining features in the anatomy section and again in the pose section. Use explicit counts.

Why. A feature mentioned once is treated as optional. The Nekomata prompt produced one tail instead of two until the prompt said "two separate forked tails, unmistakably divided".

3.10 Use even counts for repeated parts

Rule. For repeated heads, tails, arms or eyes, ask for 2, 4 or 6. Avoid odd numbers.

Why. Odd clusters break symmetry. A nine-headed giant produced a ninth head misplaced on the body. Eight heads in two columns of four worked, and the lore notes the implied ninth.

Arrangement. Use rows with a count per row, such as a front row of three and a rear row of four. Stop there. Adding a sentence about how the rows sit behind and between each other made the arrangement stiff and over-literal.

3.11 Place the end of any extreme elongation

Rule. When a neck, tail or limb stretches a long way, describe the journey and then name where the terminal element appears.

Why. The model draws the coiling but leaves the head or tip out of frame. The Rokurokubi neck coiled well while the head went missing.

Her neck stretches upward through the room and out through the window. At the far end of the neck, outside the window, her head is clearly visible, turned to face back inward.

3.12 Describe transformation part by part

Rule. Never write mid-transformation alone. State which parts have changed, which have not and what the boundary looks like.

Why. Vague wording makes the model show the creature holding or standing beside the object. The Bakedanuki produced a tanuki carrying a teapot.

The lower body and belly have become a cast-iron teapot with a heavy lid, curved spout and looping handle. The creature's face, forepaws, hind legs and tail still emerge from the iron vessel, with flesh and fur fused to cast iron at the seam.

3.13 Use emaciation words, never skeletal

Rule. Do not write skeletal, bony fingers or every rib visible as a ridge for a flesh-covered figure.

Why. Skeletal produces exposed bone. The rib phrasing produces a bare ribcage.

AvoidSkeletal arms. Bony fingers. Every rib visible as an outlined ridge.
UseGaunt, emaciated, severely wasted. Ribs pressing through papery skin as raised lines, not exposed bone.

3.14 Name garments and period features

Garments. Use the cultural term and describe construction. Long coat produced a modern blazer and robe produced a wizard. A furisode kimono described by its crossing front panels, deep V collar and sleeves hanging past the waist rendered correctly.

Faces. The model defaults to modern Western faces. Name each period convention and describe it geometrically. The hikimayu brows of Heian-era women became "two small flat rectangular outlined marks high on the forehead, each empty white inside, brow ridge completely bare". All four Heian-era women then rendered correctly.

Hair. The word straight is not enough. Add NOT qualifiers: "long straight hair, NOT wavy, NOT curly, NOT exploding outward. Each strand drawn as an individual straight outlined line." This is one of the few places where negation worked, because it gave the model a positive description alongside it.

3.15 Make the figure fill the frame

Rule. Use at least three reinforcing scale phrases.

Why. The model places figures small and distant in a landscape. One instruction is ignored. Hitotsume-kozo needed several regeneration passes before the figure filled the frame.

The [creature] fills the page from the lower edge to the crown. Its form dominates the composition, large, close, filling the centre of the image from top to bottom. This is not a small distant figure in a landscape but a looming presence that occupies the full frame.

3.16 Dynamic poses

Rule. For a figure in action, use the word heroic and describe flowing elements such as hair, wings, mane or serpent tails in motion.

Result. Adding "stands firm in heroic pose, hair waving in the wind of the impact" turned a static Hrungnir into a dynamic low-angle fighter. Use it with a grimace and not an open roar.

Line art and fills

A colouring page fails if it contains grey or solid black. The model adds both by default. These learnings keep the page clean.

4.1 Use the six-item hollow prohibition in every prompt

Rule. Ban solid fills for each type of hollow, one line each.

Why. The model fills eyes, mouths, nostrils, ears, wounds and shadows with black or grey. A general ban on solid black is read as covering only the most obvious case, which is the eyes. This matters most with hybrid creatures that have many heads and so many hollows.

Do not fill hollows of eyes with solid black or grey. Keep them empty white closed shapes.

Do not fill hollows of nostrils with solid black or grey. Keep them empty white closed shapes.

Do not fill hollows of open mouths with solid black or grey. Keep them empty white closed shapes.

Do not fill hollows of ear canals with solid black or grey. Keep them empty white closed shapes.

Do not fill wounds, body cavities, or interior forms with solid black or grey. Keep them empty white closed shapes.

Do not fill shadows of clothing, objects, or body parts with solid black or grey. Keep them empty white closed shapes.

4.2 Dark creatures default to solid black

Rule. For crows, ravens, black cats and dark scales, strengthen the fill ban and add a creature-specific sentence.

Why. The Karasutengu rendered its crow head and body in solid black even with the standard fill ban in the header.

Zero solid black fill-ins. No solid black areas anywhere in the illustration. All dark plumage, fur, scales or surfaces are rendered as fine outlined strokes only.

Its dark feathers are rendered entirely as fine outlined feather strokes with no solid black fill anywhere.

4.3 Ban cross-hatching and reinforce it at quality control

The header already forbids it. Repeat it in the negative prompt used for quality checks.

shading, gradient, grayscale, solid black fill, filled black areas, color, text, lettering, watermark, signature, border frame, cross-hatching

4.4 Keep linework language out of the scene description

Rule. The creature and background sections describe what to draw. They should not describe how lines look.

Why. Phrases such as "each crack a thin closed outline", "rendered as fine outlined strokes" and "each a closed outlined form" conflict with the header. They pull attention from form and make the result look mechanical. Quality audits showed better realism once these phrases were removed.

Also avoid. The sentence "every surface outline is a heavy closed variable-weight line". It flattened the line weight variation that the header already produces.

Exception. Section 4.2 shows that a targeted fill ban inside a creature description is useful when the creature is naturally dark. The difference is that the ban prevents a failure and does not describe style.

4.5 Describe what is present, not what is absent

Rule. Avoid no beard, no wings, no tail, no horns.

Why. Diffusion models latch onto the concept inside the negation. The Grýla beard survived two iterations of "no beard, no facial hair of any kind".

Apply. Fill the visual space with a positive description of what is there.

FailsHer chin is bare, no beard, no facial hair of any kind.
WorksSmooth bare chin and jaw, deeply wrinkled papery skin, sagging jowls, a few visible age spots, sunken cheeks.
FailsThe back is bare, no wings of any kind.
WorksThe back is smooth human musculature, with trapezius, rhomboids and latissimus dorsi drawn as contour lines. No attachment points, no wing roots.

4.6 Use realistic anatomy words for flesh and bone

See 3.13 for the emaciation vocabulary. In pale subjects such as snow, ice, frost, white fur and pale skin, the post-processing step matters too. A gentle white correction ramp (180 to 220) preserved detail where the standard soft ramp (120 to 160) pushed light mid-tones to white. Use the gentle ramp for Sleipnir, the wolves Sköll and Háti, Þrymr, Skaði and for pale stone and sand scenes.

Backgrounds

Backgrounds caused the second largest group of failures. The model reads atmosphere as a tone fill. These learnings keep scenes white and open while still giving them depth.

5.1 Never state the time of day

Rule. Do not write at night, nighttime scene, dark night, at dusk, at dawn or in daylight.

Why. The model renders the phrase as a literal grey or black background. This broke the no-grey rule in several scenes.

Apply. Describe the objects that imply the time.

Implied time or weatherDescribe instead
NightAn outlined crescent moon at the upper edge. Stars as individual outlined five-pointed forms. Foxfire flames as outlined teardrops.
DawnA low winter sunrise through loose cloud and light-ray contours. Bare branches reaching into open white sky.
Midday desertA sun disk as an outlined circle at upper centre. Heat-haze contour lines rising from the sand.
StormNaturalistic storm cloud contour forms, dramatically massed.

5.2 Control the sky and ban dot fills

Rule. Use a standard sky clause in every prompt that shows sky. Always ban dot fills and star fields.

Why. The model scatters grey dots across open white areas, even in scenes that are not night scenes.

Clouds. The volumes disagreed, and the disagreement is instructive. The Yokai volume banned clouds by default, because clouds kept rendering in front of trees and figures. The Ajaib volume asked for sparse outlined clouds, because a fully empty sky looked unfinished in print. Choose per volume, and use clouds with lore-driven storm scenes in either case.

Open sky with sparse naturalistic clouds rendered as clean outlined contour forms. Each cloud is a closed curved shape with no fill, no grey wash and no dot texture. The sky between the clouds is pure white. No dot fills, no grey dots, no star field anywhere. No solid fills anywhere in the sky or background.

5.3 Keep horror out of the sky

Rule. Do not rely on a dark sky for horror atmosphere.

Why. Describing a dark night fills the sky with black. Banning that and demanding an open white sky fixed the fill but lightened the whole scene. Hitotsume-kozo showed this. Version 2 had perfect horror with a black sky. Version 3 had a clean sky with weak horror.

Apply. Specify an open white sky with only outlined cloud shapes and a crescent moon. Carry the horror in the creature and the foreground, with predatory stillness, a blank expressionless face, wrong anatomy, lantern shadows, cracked stone and dead vegetation.

5.4 Ask for realistic backgrounds

Rule. State that landscape and architecture are realistic illustration.

Why. The model renders backgrounds in a flat comic style even when the creature is realistic. The Yuki-onna forest had stylised trees.

All background and landscape elements rendered as a realistic illustration, detailed, naturalistic and three-dimensional, not stylised, simplified or comic-book linework.

5.5 Use named cultural vocabulary

Rule. Name architecture, vessels, weapons and garments by their historical terms.

Why. Generic nouns such as old boat, wooden house or stone pillar give anachronistic or vague results.

5.6 Props need placement, pattern and substitution control

  • Placement. Props that can hang will hang. A floor-standing andon rendered as a lantern hung over the figure. Write "floor-standing, resting on the floor, not hanging, not suspended. No ceiling chains, no ropes, no hooks anywhere in the image."
  • Pattern. The model applies a default surface pattern. A paper globe lantern showed latitude and longitude lines and read as a cage. Adding "horizontal rib lines only, no vertical lines, no grid" fixed it.
  • Substitution. For unusual props the model swaps in a familiar object. The andon became a cauldron. List the wrong substitutes: "explicitly a round paper lantern resting on the floor, not a cauldron, not a pot, not a barrel, not a hanging lantern."
  • Size. A drinking bowl is too small to hold a head. Use a large cauldron with ring handles and feet.

5.7 Draw sand and snow with contour lines

Why. Phrases like sandy desert produce beige or grey tone fills.

Sand dunes rendered as clean sweeping contour lines. Each dune is defined by its ridge line and flowing slope contours, completely white between the lines. No tone fill, no stippling, no shading.

5.8 Keep placement physically coherent

Rule. Do not anchor a very large creature to a small background feature.

Why. A seven-headed serpent as wide as a river barge cannot coil at a narrow stone embankment. The model silently shrinks the creature or ignores the embankment.

Apply. Describe the background as an independent field that fills the frame around the creature. For the serpent, a river surface fills the lower frame, a low far bank sits on the horizon and a blank white sky sits above. Before writing a placement, ask whether a creature of that scale can sit there in a way the model can draw.

5.9 Leave ancient scripts out

Rule. No hieroglyphs, cuneiform or Arabic calligraphy as decoration.

Why. They render as visual noise, they shift the image towards archaeology and the creature stops being the subject. Arabic calligraphy also raises a sensitivity concern in an Islamic context. Use rosette borders, reed bundles, rope patterns and relief carvings instead. A clay tablet should have "impressed wedge-form marks" and not the word cuneiform.

Composition and references

The model is a better compositor than a layout engine. Give it intent and anchors. Do not give it coordinates.

6.1 Give camera and intent, not placement

Rule. State the camera angle, the scale and the dominant gesture. Do not say which edge a tail runs off or where a head sits in the frame.

Why. Strict positions remove the model's room to find a coherent arrangement. Limbs float, parts overlap and anatomy bends to satisfy the brief.

Over-specifiedThe head is raised at the upper centre. The tail coils off the lower right edge. The mid-body coil brushes the left side.
IntentLow three-quarter view slightly from the side. The serpent's head is raised and angled toward the viewer. The body is too large to fit in the frame.

One exception applies. When a relationship defines the creature, such as the scorpion tail arching over Girtablullu, describe it against the body and not against the frame.

6.2 Reinforce full bleed at scene level

Rule. Do not rely on the closing paragraph alone.

Why. The closing sits at the end of a long prompt and earlier framing can override it.

The [creature and scene elements] extend to every edge of the frame. The [background element] runs off the top, the [foreground element] runs off the bottom, and [lateral elements] run off both sides.

6.3 Ground complex scenes in a film reference

Rule. When a scene has many elements or tricky perspective, pick a well-known film scene with the same composition. Ask for that scene, then replace each element one for one.

Why. The model has absorbed a great deal of cinematic imagery. A film scene supplies the camera angle, the placement and the sense of scale that abstract description fails to convey.

  1. Identify the film scene whose composition matches your vision.
  2. Prompt: "Dramatic [angle or shot] of a composition of [film scene description]."
  3. Then: "Replace [film character] with [your subject]. Replace [film element] with [your element]. Replace [background] with [your background]."
  4. Keep the replacements clean and one for one. Add no new elements in this step.

Worked example. Möðguðr, a guardian woman on a long bridge facing a portal to the underworld, failed in versions 1 to 3 from abstract description. Version 4 used Gandalf confronting the Balrog on the bridge in the Mines of Moria. Gandalf became a Nordic woman. The Balrog became a portal to oblivion. The cave became an overcast underworld sky. The river stayed. It produced the correct wide-angle confrontation in one pass.

The Ajaib volume applied the same method to place a Lamassu at the Ishtar Gate from a dramatic low angle.

6.4 Style references help, but they can contaminate

Benefit. In the Yokai volume, passing one approved image as a style reference through the image edit endpoint raised detail density, background realism and linework. The prompt stayed unchanged, because the reference steers style and not subject.

Risk. The chosen reference showed a cloth smothering a victim with arms raised above an obscured head. On a close-up portrait of a standing humanoid, the model copied that silhouette. It produced floating hands and a round blank head. It also pulled in a solid dark sky.

Rule. Do not use a reference whose pose or silhouette is distinctive for close-up portraits or upright frontal figures. Generate those from text alone and check any new portrait against this risk first.

6.5 Do borders and margins in post-processing

Finding. Six attempts with different phrasings failed to get a precise 1/8 inch white margin and a single unbroken border. Phrasings tried included single unbroken line with no inner margin line, picture-frame mat framing and capitalised CRITICAL emphasis. An image generator is not a layout engine.

Rule. Remove every border and margin instruction from the prompt. Add the border with a script such as Pillow after generation.

Bleed update. The book later moved to a print format with bleed, where the border runs to the canvas edge on purpose. The script handles that case too. The prompt stays free of layout rules in both formats.

The same logic explains the standard closing line, which carries no margin reference. Layout belongs to the template and the print file.

Moderation and sensitivity

Some prompts are rejected before any image is made. Each rejection still costs a credit. These learnings came from rejected prompts.

The rejections are classifier behaviour. They respond to phrases as much as to content. When a harmless scene is rejected, suspect the wording before the subject.

7.1 Realism disclaimers trigger rejection

Avoid. Not a cartoon, not a comic book, not a fantasy illustration, every proportion must be based on realistic human anatomy, the figure is a real physical subject.

Why. The classifier reads these as an intent to produce a realistic depiction of a real human. Rejections that the scene alone could not explain disappeared once the phrases were removed.

Fix. Delete them. The style header and a specific anatomical description give realistic proportions without the risk.

7.2 Always dress figures

Avoid. No clothing, bare-bodied, or framing the body as the only subject.

Why. A prompt for a frost giant with no garment was rejected with HTTP 400 and the code imagine:content-moderated. This happened whatever the creature's nature or the artistic intent.

Fix. Add covering that suits the creature, even where the lore says it is naked.

  • Cold-realm giant: massive fur pelts and rough-hewn ice-encrusted armour.
  • Spirit figure: tattered grave-wrappings or trailing spirit-cloth.
  • Aquatic creature: seaweed wrapping or barnacle-encrusted shell armour.
  • Pazuzu: a knotted linen loincloth, a narrow cloth panel front and back secured by a knotted cord, in place of the explicit iconography.
  • Lilitu: a diaphanous linen robe, fine contour lines following the body form, with no skin exposed. This also reads as more uncanny than nudity.

7.3 Soften severed or preserved heads

Avoid. Preserved head, severed, clean-cut neck.

Why. The Mímir prompt, version 2, was rejected and billed with the words "preserved head" in both the context paragraph and the subject sentence.

Fix. Write "the head of a very old wise man, calm and watchful, rests in the herbs" and keep the context to "whose counsel Odin kept after death". Use a large cauldron and a high camera angle so the rim does not hide the head. A short expert-context paragraph at the top, such as "You are an expert in Norse folklore and mythology", helped. Three short paragraphs beat the earlier long drafts.

7.4 Frame djinn as folklore, never theology

Rule. Describe djinn as creatures of pre-Islamic Arabian folklore and the medieval Arabic storytelling tradition.

Avoid. Islamic spirit, a spirit mentioned in the Quran, jinn of Islamic tradition, demonic entity of Islam.

Why. Theological framing risks a refusal and conflicts with the series' sensitivity guidelines.

Apply. Describe form only. An Ifrit is fire-born and a Marid is ocean-born. A Ghul is a shape-shifter of graves and desert. A Nasnas is a half-human with one arm, one leg and one eye. A Si'lat is a shape-shifter who appears fully human.

Workflow and quick reference

Good prompts need a good process around them. These habits protected approved work and saved credits.

8.1 Review the prompt before generating

Write the prompt to a file and show it in full. Wait for explicit approval, such as approved, go or generate. Do not proceed on implied approval. Review catches wrong anatomy, banned phrases and category mismatches before a credit is spent.

8.2 Back up before overwriting

Copy the current file to a versioned backup before each regeneration, such as NN-name-v1.png. Version 2 of the Kappa was overwritten by version 3. The user preferred version 2 and it could not be recovered. When a version is accepted, move the backups to an archive folder.

8.3 Report the file path after each generation

Give the saved path as a clickable relative link. It confirms at once that the right file went to the right place.

8.4 Save the exact accepted prompt immediately

If generation went from version 1 to version 3, the prompt file must hold the version 3 text and not the first draft. Update the status tracker to approved with the version number. Do both before opening the next creature. The prompt file is the permanent record for consistency and later regeneration.

8.5 Keep the learnings document alive

Each review that exposes a repeatable issue gets a new numbered learning with the creature where it first appeared. Apply every learning to new prompts and retrofit it to prompts not yet generated. Where a learning exposes a process gap, add a matching item to the quality checklist.

Pre-generation checklist

  • The prompt leads with a visual description and not a name.
  • Humanoids start from human anatomy with no category words.
  • Defining features appear twice and counts are even.
  • No time-of-day words. The sky clause is present.
  • The six-item hollow prohibition is present.
  • Negations are replaced by positive descriptions.
  • Cultural terms are named and props have placement and substitution notes.
  • Camera and scale are stated and no body part has a coordinate.
  • Full bleed is reinforced in the scene text.
  • No realism disclaimers. Every figure is dressed.
  • No border or margin text. No script decoration.
  • A backup of the current file exists and the prompt has been approved.
